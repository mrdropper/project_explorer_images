# Проводник работы с изображениями

Десктопное приложение на Python с графическим интерфейсом (PyQt6) и локальной базой данных SQLite для удобного каталогизирования, просмотра, переименования и базового редактирования изображений.

## Основные возможности

* **Управление коллекцией изображений:**
  * Добавление файлов форматов `.png`, `.jpg`, `.jpeg`, `.webp` (одиночно и списком).
  * Автоматический контроль дубликатов имён и конфликтов файлов на диске с присвоением номера копии в формате `имя (n).расширение`.
  * Умное переименование файлов: автоматическое обновление имени в БД и на диске, а при наличии связанных копий — безопасное создание отдельного файла с сохранением исходного оригинала.
  * Просмотр подробных свойств файла: исходное имя без расширения, формат и статус копии (`оригинал` или номер копии).
  * Удаление отдельных записей или полная очистка базы данных.
  * Экспорт таблицы с данными об изображениях в формат `.csv` (с разделителем `;`, кодировкой UTF-8 с BOM и экранированием дат для корректного открытия в Excel).

* **Просмотр и встроенный редактор:**
  * Предпросмотр изображений в отдельном окне по двойному клику в таблице.
  * Поворот изображения на 90° влево и вправо.
  * Рисование кистью с выбором произвольного цвета и толщины линии (от 1 до 50 пикселей).
  * Ластик для стирания элементов.
  * Произвольная обрезка (кадрирование) выделенной области с предпросмотром рамки.
  * Сохранение отредактированного файла (при сохранении под новым именем файл автоматически добавляется в базу данных).

## Стек технологий

* **Язык:** Python 3
* **GUI-фреймворк:** PyQt6
* **База данных:** SQLite3 (`app_data.db`)

## Структура проекта

* `main.py` — основной исполняемый файл с логикой приложения, работой с БД и окнами (`Main`, `Features`, `OpenedImg`, `Redactor`).
* `mainmenu.ui` — интерфейс главного окна со списком файлов.
* `OpenedImg.ui` — интерфейс окна предпросмотра изображения.
* `Redactor.ui` — интерфейс графического редактора.
* `features.ui` — интерфейс окна свойств файла.
* `app_data.db` — база данных SQLite с таблицами `images` и `name_details`.
* `requirements.txt` — список зависимостей проекта.

## Установка и запуск

1. **Скачайте или клонируйте файлы проекта** в одну папку.

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение:**
   ```bash
   python main.py
   ```
   *(Убедитесь, что все `.ui` файлы и `app_data.db` находятся в одной директории со скриптом запуска.)*
